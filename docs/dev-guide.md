Миграции создаёт только один назначенный человек, остальные делают git pull и применяют готовые. Иначе будут дубликаты миграций и конфликты в снапшоте.

Если добавляешь новую зависимость в конструктор ViewModel — сразу добавь её регистрацию в DI. Иначе приложение упадёт на старте с InvalidOperationException: Unable to resolve service, и это будет неочевидно.
